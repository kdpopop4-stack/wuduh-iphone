# وضوح للآيفون

تم بناء نسخة iPhone أصلية بنجاح باستخدام Xcode على GitHub Actions.

- [نتيجة بناء IPA الناجح](https://github.com/kdpopop4-stack/wuduh-iphone/actions/runs/40449109160).
- [تنزيل IPA غير الموقّعة](Wuduh-iPhone-unsigned.ipa).
- [دليل التثبيت والتوقيع من Windows](BUILDING_AR.md).
- المصدر الكامل والنموذج والتراخيص داخل Wuduh-iPhone-source.zip. فكّه لفتح Wuduh.xcodeproj. يقرأ سير العمل الحزمة ويتحقق من بصمتها قبل البناء.
- يعمل على iOS 17 فأحدث، بمعمارية ARM64. المعالجة داخل الهاتف، دون رفع الفيديو لخادم أو API مدفوع.

## التثبيت

لا تُثبّت IPA غير الموقّعة بمجرد فتحها على الآيفون. وقّعها وثبّتها من Windows باستخدام Sideloadly من موقعه الرسمي [Sideloadly](https://sideloadly.io/)، وأدخل حساب Apple بنفسك داخل البرنامج. التوقيع المجاني يحتاج عادةً تجديدًا كل 7 أيام. Windows مطلوب للتثبيت والتجديد، بينما معالجة الفيديو تعمل على الهاتف.

## الميزات والحدود

Real-ESRGAN محلي، وتوليد إطارات بتقدير الحركة على Metal، وإخراج يصل إلى 4K و60 إطارًا حسب إمكانات الجهاز. معاينة ألوان وإضاءة وظلال ولمعان، وتجربة 3 ثوانٍ، وتقسيم المعالجة واستكمال الأجزاء المكتملة. لا يوجد حد ثابت 100 ميجابايت؛ المساحة والحرارة والذاكرة تحدد حدود الاستخدام.

AI يقدّر التفاصيل ولا يستعيد معلومات الكاميرا المفقودة بصورة مضمونة. قد تظهر تفاصيل متخيلة أو تشوهات حركة. لا يمكن تحديد طراز الكاميرا بثقة إن لم تتضمن بيانات الملف ذلك. الإخراج SDR، ودقة عمل AI الافتراضية 960 بكسل لتقليل الذاكرة؛ تصدير 4K لا يضمن تفاصيل أصلية بدقة 4K.

## التحقق

نجح بناء وأرشفة إصدار الهاتف وفحص IPA: ملف تنفيذي ARM64، والنموذج الصحيح، وMetal، وبصمة SHA256. التفاصيل في Wuduh-iPhone-build-verification.json.

نجحت اختبارات توليد إطار وسيط والإيقاف والتصدير في تشغيل محاكي سابق. ظهر خطأ Core ML خاص بالمحاكي، فأصبح المحاكي يستخدم CPU. التشغيل الكامل الأحدث تعلّق بعد التجميع وأُوقف؛ لا ندّعي نجاح المجموعة كاملة. لم تُختبر هذه النسخة على آيفون فعلي ولم تُوقّع بعد. ابدأ بمقطع قصير بعد التثبيت.

يمكن إعادة البناء يدويًا من Actions → Build iPhone IPA → Run workflow. يُفضّل تشغيل الاختبارات. لم يُضف تشغيل تلقائي عند رفع الملفات، ولم تُغيّر إعدادات الإنفاق.
